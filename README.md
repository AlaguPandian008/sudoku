# Sudoku CLI Game

A simple command-line Sudoku game built using Java.

## Requirements

- Java 17+
- Maven
- IntelliJ IDEA (recommended)

---

# How to Run

## Using IntelliJ

1. Open the project in IntelliJ
2. Open `Main.java`
3. Click **Run**

---

## Using Maven

Open terminal in project folder:

```bash
mvn clean install
mvn exec:java -Dexec.mainClass="com.example.sudoku.Main"
```
